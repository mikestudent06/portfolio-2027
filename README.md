# Michel Mouhani — Portfolio 2027

Site Next.js du portfolio de Michel Mouhani : expérience 3D (bureau → écran → projets) et pages indexables pour le SEO.

## Démarrer

```bash
npm install
cp .env.example .env.local
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Contenu

Tout le texte, les projets et les liens se trouvent dans `lib/content.ts`.

`NEXT_PUBLIC_SITE_URL` doit pointer vers le domaine de production (canonical, sitemap, Open Graph).
